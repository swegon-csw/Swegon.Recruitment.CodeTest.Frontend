# Swegon Recruitment Frontend

React TypeScript application for Swegon recruitment code test.

## Prerequisites

- Node.js >= 20.0.0  ([download](https://nodejs.org/en/download))

## Installation

Clone the repository and install dependencies:

```bash
git clone <repository-url>
npm install
```

## Running the Application

Start the development server:

```bash
npm start
```

The application will be available at `http://localhost:3000`

## Tech Stack

- React 19
- TypeScript 5.2
- Vite
- React Router v7
- Styled Components
